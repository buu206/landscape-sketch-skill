# 景观分析图工作流

适用：流线、功能分区、日照、视线及概念分析。采用扁平表达或轻量马克笔底图。

每张图聚焦一个分析主题；多主题使用同一底图分张表达。流线用方向箭头及线型，功能分区用少量色块，视线说明观察点与目标。日照需位置、朝向、日期、时刻及遮挡信息；资料不全时标明示意，不编造计算结果。

## 英文内容模板
```text
A clear landscape concept diagram showing {analysis_theme} for a {site_type}. Use a simplified orthographic base plan with stable site boundaries and essential contextual features. Overlay {directional_arrows_or_zones_or_view_cones}, use {limited_color_palette} with distinct line styles, and emphasize {main_design_relationship}. Reserve space for a concise legend and a title. Keep a clear graphic hierarchy and a subdued background. {assumption_or_schematic_note_if_needed}
```

技术约束：默认 4:3；分张图使用同一底图、朝向和比例；颜色不足以区分时增加线型或纹理。

负面词：`decorative clutter, excessive gradients, overlapping arrows, ambiguous legend, photorealistic detail, unsupported numerical claims`。

检查：箭头无矛盾、分区与出入口相容、图例覆盖所有符号、日照假设明确。
